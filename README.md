# El Rey David

Juego cristiano en 3D sobre el joven David: pastor, el león y el oso, la unción de Samuel y el gigante Goliat.
Hecho con Godot 4.7.

**Jugar:** https://yaredcerdatorres-star.github.io/el-rey-david/

En el iPhone: abre el enlace en Safari → Compartir → «Agregar a pantalla de inicio» para jugar a pantalla completa.
